# Daibiko Power BI Dashboard

## Project Overview
This project presents an interactive Power BI dashboard built using the Daibiko manufacturing dataset. The dashboard helps analyze production performance, defect rates, product categories, and regional sales to support data-driven business decisions.

## Objectives
- Analyze manufacturing performance
- Monitor product sales
- Identify defect trends
- Compare regional performance
- Track KPIs

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Features
- Executive Summary
- KPI Cards
- Sales Analysis
- Defect Analysis
- Regional Insights
- Interactive Filters

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Data Visualization
- Dashboard Design
- DAX

## Project Outcome
Developed an interactive dashboard that converts raw manufacturing data into meaningful insights for business decision-making.
